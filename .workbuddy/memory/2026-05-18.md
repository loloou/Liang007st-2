## 余额查询功能优化（借鉴 all-api-hub）

### 参考项目
- [all-api-hub](https://github.com/qixing-jk/all-api-hub)：浏览器扩展，管理多中转站余额/用量/签到
- 核心思路：站点类型预设 + `/api/status` 动态汇率 + 三层降级自动探测

### 改动文件

#### `client/src/api/balance.ts` — 完整重写
- **扩充站点预设**：从 3 种 → 10 种 (one-api, new-api, one-hub, done-hub, veloera, v-api, vo-api, super-api, sub2api, aihubmix)
- **动态汇率获取**：新增 `fetchSiteStatus()` 函数，从 `/api/status` 获取站点实际汇率
  - 优先级：`price` → `stripe_unit_price` → `PaymentUSDRate` → 默认 7.2
- **统一 quota 提取**：One API 系列共享 `extractOneApiQuota()` 函数
- **错误分类系统**：新增 `BalanceErrorCode` 类型（10 种错误码），每种有对应图标和建议
- **自动探测优化**：三层降级策略
  1. 先查 `/api/status` 获取站点信息和汇率（公开端点，无需认证）
  2. 根据 status 数据推断站点类型
  3. 再按优先级探测余额端点
- **认证失败立即返回**：401/403 不再 continue，而是返回明确的认证失败信息

#### `client/src/components/BalancePopup.tsx` — 增强
- 站点类型标签显示（每张卡片右上角）
- 汇率来源显示（"站点配置" / "默认"）
- 错误提示优化（每种错误码有专属图标和操作建议）
- 新增 `onRefresh` 回调（标题栏刷新按钮）

#### `client/src/api/settings.ts` — 类型扩展
- `BalanceConfig.siteType` 从 4 种扩展到 11 种

#### `client/src/components/SettingsDialog.tsx` — 预设映射更新
- 站点类型切换时的预设映射表同步更新

#### `client/src/App.tsx` — 传入 onRefresh

## 余额查询 CORS 修复 + 默认站点类型

### 问题
1. 新建配置默认站点类型为 `one-api`，用户更常用 `new-api`
2. 点击测试连接报 `Failed to fetch`，浏览器 CORS 限制导致前端直接请求第三方 API 失败

### 改动

#### 1. 默认站点类型 `one-api` → `new-api`
- `SettingsDialog.tsx`：3 处新建配置的 `siteType` 默认值改为 `"new-api"`
- `SettingsDialog.tsx`：`<select>` 的 fallback 值从 `"one-api"` 改为 `"new-api"`

#### 2. Electron 主进程代理（绕过 CORS）

**`electron/main.js`**：
- 新增 `ipcMain.handle('fetch-request', ...)` IPC 通道
- 在主进程使用 Node.js 原生 `fetch` 发请求（无 CORS 限制）
- 返回 `{ ok, status, statusText, headers, body, error? }`

**`electron/preload.js`**：
- 新增 `fetchRequest` 方法暴露到 `window.electronAPI`

**`client/src/types/electron.d.ts`**：
- 新增 `FetchRequestParams` / `FetchRequestResult` 类型
- `ElectronAPI` 接口新增 `fetchRequest` 方法签名

**`client/src/api/balance.ts`**：
- 新增 `proxyFetch()` 通用代理函数
  - Electron 环境：优先使用 `window.electronAPI.fetchRequest`（无 CORS 限制）
  - 非 Electron 环境：回退到浏览器 `fetch`（可能受 CORS 限制）
- `fetchSiteStatus()`、`fetchWithConfig()`、`fetchAutoDetect()` 全部改用 `proxyFetch()`

**`client/src/components/SettingsDialog.tsx`**：
- `testBalanceConfig()` 改用 `proxyFetch()`，不再手动判断 Electron 环境
- import 新增 `proxyFetch`
